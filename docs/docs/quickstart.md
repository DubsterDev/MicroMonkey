# Quick Start

:::tip
If you haven't already, you may need to [flash MicroPython](./flash-micropython) to your board.
:::

The fastest way to get started is to go to [the IDE](/ide/){target=_blank} in a Chromium based browser and click the `Connect to Board` button in the bottom left.

:::info
If anything doesn't work, please see the [troubleshooting page](./troubleshooting).
:::

If the file explorer loaded, go ahead and click a file to open it in the editor. If it didn't, try clicking the reload button next to the `Files` text once or twice.

In the editor, you'll notice MicroMonkey has [syntax checking and intellisense](./intellisense), providing you with realtime feedback as you type code.

At the bottom of the editor area is the [serial monitor](./serial-monitor).

When you're done making changes be sure to save the file with the button on the bottom or the keyboard shortcut `Ctrl+S`. By default, MicroMonkey will reboot the connected device after saving the file, but you can disable this in settings.
