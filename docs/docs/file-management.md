# File Management

:::tip
You may need to click the reload button in the Files heading once or twice to get the file explorer to load.
:::

Managing files on your board is easy with MicroMonkey. Once the file explorer has loaded, you should see a list of files on your board.

Your files are grouped by folders. You can expand folders by clicking on the name of the folder, which will reveal all the folders and files inside it.

When you click on a file, MicroMonkey will get the contents of the file and open a new tab in the editor with the contents of the file. This is typically pretty fast, but if you have a really big file it can take a little bit of time to load the editor.

In the editor, you'll notice you can type and you'll get code autocompletions. You can read more about how this works at the [intellisense guide](./intellisense).

When you right click a file or folder (or press and hold on mobile), you'll see a context menu containing file management actions, specifically `Delete` and `Rename`.

On the `Files` header, and on nested folders, you'll see buttons for creating new files and folders. When you click these, you'll get a input prompt for the name of the file or folder.

When you hit Enter on your keyboard, MicroMonkey will create the file or folder for you. You can then open the file or folder by clicking it in the Files pane on the left of the editor.
