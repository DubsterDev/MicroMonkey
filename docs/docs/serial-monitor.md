# Using the Serial Monitor

MicroMonkey comes with a built-in serial monitor so you can see what your board is doing. Output from your programs will display here, and you can also execute MicroPython code in there as well.

At any time you focus the serial monitor and press `Ctrl+C` to terminate a running program and you'll be taken to the MicroPython REPL. You can learn more about the REPL at [MicroPython's REPL docs](https://docs.micropython.org/en/latest/reference/repl.html).

You'll also notice that when you perform actions involving the board MicroMonkey runs code in the REPL. When you're opening a file, for example, you'll see the contents of the file in the REPL as MicroMonkey gets it from your board.
