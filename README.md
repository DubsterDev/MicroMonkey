MicroMonkey is a web-based IDE for managing code on MicroPython devices.

You can try it out at [MicroMonkey.web.app](https://micromonkey.web.app)!


## Features
 - Serial Monitor
 - File Explorer
 - Multiple tabs
 - Create files/folders
 - Rename files/folders
 - Delete files/folders
 - Adaptive dark/light theme, based on your OS setting
 - MicroPython flashing (`CTRL+SHIFT+P` > Flash MicroPython)


## Stages

### Stable/Release

This stage is shown when MicroMonkey has not been modified since the latest stable release, always accessible at [MicroMonkey.web.app](https://micromonkey.web.app)

### Beta

This stage is shown when MicroMonkey is in beta. MicroMonkey is typically in this stage for a week before going stable. The latest beta release is accessible at [MicroMonkeyBeta.web.app](https://micromonkeybeta.web.app)

### Preparing for Beta

This stage is shown when MicroMonkey has not been released to any stage yet. You can run this version of MicroMonkey by following the instructions in [CONTRIBUTING.md](CONTRIBUTING.md).

The latest stable release can be found at [MicroMonkey.web.app](https://micromonkey.web.app) and the latest beta can be found at [MicroMonkeyBeta.web.app](https://micromonkeybeta.web.app), though these are normally the same in this stage.
